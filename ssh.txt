Step 2: Transfer the Built .next Directory to Remote

From your local machine, use rsync to sync only the .next build folder and public assets:

bash
# Run from repository root:
rsync -avz --delete \
  -e "ssh -i ~/.ssh/factorytribe-oracle.key" \
  --exclude 'cache' \
  apps/storefront-wholesale/.next/ \
  ubuntu@130.210.44.243:/home/ubuntu/factorytribe/apps/storefront-wholesale/.next/

Why --exclude 'cache'? The .next/cache directory contains massive internal webpack cache files (~300MB+) that are only needed for subsequent local rebuilds. Excluding it makes the transfer fast (usually under 20–30 MB) and takes only a few seconds.

If you have static assets in public/, sync those as well:

bash
rsync -avz \
  -e "ssh -i ~/.ssh/factorytribe-oracle.key" \
  apps/storefront-wholesale/public/ \
  ubuntu@130.210.44.243:/home/ubuntu/factorytribe/apps/storefront-wholesale/public/
